# My Golf Lounge

골프 라운드 기록·분석 웹앱입니다. 필드에서 휴대폰으로 기록하고, 어느 기기에서든 같은 기록을 보고 분석합니다.

**주소**: https://supok00.github.io/golf-lounge/ · 현재 버전 **v1.1** (2026.10.26 중복 정리판, 이전 v1.0은 `/v1.0`)

> 골프라운지(golflounge.co.kr) 개인 통계 화면의 분위기를 참고해 만든 개인 프로젝트입니다. 제휴·공식 서비스가 아니며 브랜드·로고는 쓰지 않습니다.

## 만든 이유와 지나온 길

| 단계 | 저장소 | 한 일 |
|---|---|---|
| 출발 | 「골프 라운드 분석_v2.xlsx」 | 홀별 17개 항목 스코어카드와 분석표. 2026.10.21 고정본으로 두고 더 고치지 않음 |
| 1 | [golf-round-web](https://github.com/supok00/golf-round-web) | 엑셀을 웹으로 옮김 — **필드에서 휴대폰으로 입력**하고, 데이터는 GitHub 저장소에 두어 **어느 기기에서나 같은 기록**을 보도록. 휴대폰은 앱 설치(PWA)로 사용 |
| 2 | [mygolf](https://github.com/supok00/mygolf) | 기능 확장 — 공통 필터, 스코어 유형, 안정성, 베스트 TOP 10, 추이 자동 집계, 인사이트, 스마트스코어 붙여넣기 등록 |
| 3 | **golf-lounge** (이 저장소) | 파스텔 화면으로 새로 만들고, 가이드·Fork·지역 지도·동반자 기록·사진 등을 더함 |

세 저장소의 데이터를 서로 동기화해 쓰다가, **2026.10.25부터 golf-lounge 하나로 관리**합니다. golf-round-web·mygolf는 「golf-lounge로 옮겼습니다」 안내가 뜨는 보기 전용 페이지로 남겨 두었습니다(저장 안 됨, 데이터는 그 시점에서 멈춤).

## 기능

- **홈(대시보드)**: 등록 라운드·평균·베스트·최근 5R, 목표 대비 실력 진단, 6영역 육각형(드라이빙·아이언·숏게임·퍼팅·거리감·위기관리), 타수 손실 원인, 강점·약점, 타수 추이(5R 이동평균 대비 색)
- **공통 필터**: 기간(전체·최근 90일·이번 달·지난 달·연도), 골프장 검색, 18홀만 — 모든 분석 화면에 같은 조건
- **통계**: 스코어 유형(이글·버디·파·보기…), 안정성(표준편차·최근 10R), 베스트 TOP 10, 스코어 구간 도넛, 연도·골프장별
- **인사이트**: 올해 누적, 라운드 간격·요일·오전/오후, 최근 90일, **다녀온 지역**(한국 지도에 시·도별 골프장 수), **동반자 전적**(승-패-무·평균 차)
- **홀·파 분석 / 상세 분석**: 파 유형·홀 번호별, 엑셀 v2 「상세분석」 표 + 홀 길이별·드라이버 거리별·예상 어프로치 클럽별
- **라운드 목록·상세**: 엑셀과 같은 OUT/IN 스코어카드, 이 라운드 6영역, **동반자 비교**(순위·홀별 Par 대비·홀 매치), 사진
- **라운드 입력**: 홀마다 17개 항목(Par·스코어·퍼트·벌타, 거리·핸디캡, FW·티샷 미스·티샷 거리, 온그린 타수·1st 퍼트 거리, 그린 미스·어프로치·벙커·숏게임) + 날짜·골프장·코스·티·**지역**·날씨
  - 위에서 적은 값으로 아래 칸 자동 입력(직접 고치면 그 값 우선), 파3 「.」·파5 「-」 표시
  - 같은 골프장·같은 티의 이전 라운드에서 Par·거리·핸디캡 불러오기, 내 클럽 거리로 홀 공략 가이드
  - 입력 중 내용은 기기에 임시 저장
- **붙여넣기 등록**: 네이버 스마트스코어 텍스트(여러 라운드 한 번에, 홀 길이 줄 포함), **선수 이름 줄로 된 스코어카드 표**, **사진만 첨부**(글자 인식) — 내 줄을 고르면 나머지는 동반자로
- **동반자**: 스코어만·붙여넣기·사진·**홀별 직접 입력**, 가려진 이름(홍*동)은 고치기 전에는 저장 안 됨
- **설정**: GitHub 토큰, 내 클럽 거리, 목표·육각형 기준, 버전·변경 내역, 백업
- 📖 **가이드** 메뉴, 휴대폰 **앱 설치(PWA)**와 「새 버전이 있습니다 — 지금 적용」 알림

**메뉴(2026.10.26 정리)**: 홈 · 분석(스코어·홀파·샷 분석) · 인사이트 · 라운드 목록 · 라운드 입력(직접 입력·붙여넣기·사진) · 가이드 · 설정. 겹치던 통계·분석·설정 15곳을 정리했고 내역은 사이트의 `#/review`에 있습니다(정리 시안은 [golf2](https://github.com/supok00/golf2)).

## 데이터 — GitHub 저장소가 원본

- 라운드는 `data/rounds.json`, 기준값·클럽 거리는 `data/settings.json`, 사진은 `data/photos/`에 저장됩니다.
- **보기**: 페이지가 GitHub API로 최신 파일을 읽습니다(공개 저장소라 토큰 불필요). API 한도(시간당 60회/IP)를 넘으면 배포본을 읽어 몇 분 늦을 수 있습니다.
- **저장**: 입력하는 기기에서 한 번만 설정 → GitHub 토큰을 넣습니다. 저장할 때마다 커밋이 생겨 변경 이력이 모두 남고, 다른 기기가 먼저 저장했으면 최신본에 다시 적용합니다.
- 토큰: GitHub → Settings → Developer settings → **Fine-grained tokens** → Only select repositories: `golf-lounge` → **Contents: Read and write**, 만료 90일 정도. 토큰은 그 브라우저에만 저장되며 공용 PC에는 넣지 마세요.

> **공개 저장소입니다.** 기록(날짜·골프장·스코어)과 사진은 누구나 볼 수 있습니다. 동반자 이름은 실명 대신 별명·이니셜을 쓰고, 사진은 줄여서 촬영 위치 등 사진 속 정보를 지운 뒤 올립니다.

## 다른 사람이 쓰려면 (Fork)

1. GitHub 계정으로 이 저장소를 **Fork**
2. 내 복사본의 **Settings → Pages → main / (root)** 저장 → `https://내아이디.github.io/golf-lounge/`
3. 내 복사본에만 권한이 있는 토큰(Contents: Read and write)을 만들어 사이트 설정에 입력

- 페이지 주소에서 저장소를 알아내므로 코드를 고칠 필요가 없습니다.
- Fork한 사람의 기록은 `data/users/아이디/`에 저장되고 빈 기록으로 시작합니다.
- 새 기능은 **Sync fork → Update branch**로 받습니다. 기록 파일이 달라 충돌하지 않습니다.

## 버전

- 정식판 **v1.0**(2026.10.25), 중복 정리판 **v1.1**(2026.10.26). 그 전 개발 과정은 v0.1~v0.9로 매겼습니다(예전 번호 v1.0~v1.13을 다시 매김 — v1.0~v1.5는 v0.1로 묶음).
- 작은 변경은 1.1, 1.2 …, 큰 개편은 2.0. 배포할 때 `js/version.js`를 올리고 `python3 tools/build_archives.py`로 이전 버전 화면을 만든 뒤 커밋·push, `vX.Y` 태그를 붙입니다.
- 이전 버전 화면(보기 전용): 주소 뒤에 `/v0.9`처럼 붙입니다.
